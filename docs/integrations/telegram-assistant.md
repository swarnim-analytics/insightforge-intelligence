# Telegram Assistant

## Overview

Telegram is the primary conversational interface for InsightForge-Intelligence.

The assistant provides:

- market intelligence
- portfolio updates
- infrastructure alerts
- AI-generated summaries
- operational notifications

---

## Core Capabilities

### Financial Intelligence

Commands:

/market
/nifty
/portfolio
/watchlist
/ipo
/mutualfunds
/crypto

```

Outputs:

* summaries
* scores
* opportunities
* risk observations

---

### Infrastructure Intelligence

Commands:


/server
/docker
/storage
/nextcloud
/ollama
```

Outputs:

- health status
- utilization
- alerts
- recommendations

---

### AI Intelligence

Commands:

/summary
/research
/analyze

```

Capabilities:

* summarize information
* explain analytics
* generate commentary
```
